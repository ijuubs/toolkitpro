# ToolKitPro

ToolKitPro is a free collection of in-browser web utilities, everyday calculators, developer tools, and regional Fiji calculators. All utility inputs and transformations are processed locally in your browser without uploading your files or sensitive data to remote servers.

## Features
- **Calculators & Math Tools:** Mortgage, Loan, Salary, Overtime, VAT, FNPF, ROI, BMI, and TDEE calculators.
- **Fiji Specialized Tools:** Regulated taxi fares (FCCC standards), duty & import calculator, electricity bill calculator, grocery budgeting, and TSLS repayment.
- **Developer Utilities:** JSON formatter, diff checker, base64 encoder/decoder, URL encoder/decoder, password generator, and QR code generator.
- **Media & Document Tools:** PDF compressor, PDF merger, image resizer, aspect ratio calculator, and hex/RGB color converter.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS (Neu-brutalist UI)
- Structured Data (Schema.org) & SEO Pre-rendering
